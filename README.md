# Aura Launcher v3.1 (исходник для AIDE 3.2)

Два вида рабочего стола:
- **Вид 1 — бесконечный холст.** Двигаешь пальцем, масштабируешь щипком. Стеклянные карточки и иконки приложений.
- **Вид 2 — десктоп в стиле Hyprland.** Верхняя панель, окна с заголовками (neofetch, часы, календарь, плеер),
  док снизу. Переключение: долгое нажатие на пустом месте → «Второй вид холста».

## Сборка в AIDE
1. Удали старую папку AuraLauncher (или распакуй поверх с заменой) в /storage/emulated/0/AppProjects/.
2. Открой проект в AIDE (папка AuraLauncher с settings.gradle).
3. Если AIDE ругается на SDK, в app/build.gradle поменяй compileSdkVersion на доступный (28–30).
4. Перед первой сборкой удали папку app/build (если она есть) и старое приложение Aura с телефона.
5. Run → Install.

## Первый запуск
- «Домой» → Aura → «Всегда» (или Настройки → Приложения по умолчанию → Домашний экран).
- Плеер: тапни по карточке плеера → включи доступ к уведомлениям для Aura.
  Если пункт серый: Настройки → Приложения → Aura → ⋮ → «Разрешить ограниченные настройки».

## Управление
- Холст (вид 1): двигать — перетаскивание, приблизить/отдалить — щипок, двойной тап — в начало.
- Долгое нажатие на карточке или иконке — выбрать и переместить. У выбранной появляется кружок в правом
  нижнем углу: тяни за него, чтобы изменить размер. Тап по пустому месту снимает выделение.
- Иконку можно убрать, перетащив вниз в красную зону.
- Десктоп (вид 2): окно двигается за заголовок, красная точка в заголовке скрывает окно
  (вернуть: меню → «Показать скрытые окна»). Тап по окну выбирает его и показывает ручку размера.
- Меню (обои, виды, сброс, настройки) — долгое нажатие на пустом месте.
- Все приложения — свайп вверх от нижнего края или тап по «ручке» внизу (в виде 2 ещё кнопка в доке).
- В списке приложений долгое нажатие: закрепить в доке или добавить на рабочий стол.
- Плеер: тап по волне перематывает трек.
- Экран можно поворачивать. В горизонтальном режиме включается полный экран (без панелей) и рисование под вырезом камеры.
  Масштаб холста сохраняется при повороте, расположение карточек для каждой ориентации и каждого вида хранится отдельно.
